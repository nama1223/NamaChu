## 概要

管楽器のためのチューナー。
演奏した「瞬間」ではなく「時間＋変化」で見られる機能が売りで、吹き始めだけ高いとか、まっすぐ吹けているか、なども見られます。
演奏を記録して後から再生したり、自分の楽器の癖を測って保存する機能もあります。

### チューナー
±50セントのメーターと時間グラフ表示。楽器ごとに音域レベル（初級／中級／上級／プロ）を選べます(※レベル設定は未完成)。
コンサートピッチはA=442Hzなど任意に設定可能。

### 音階記録
吹いた音階を記録してグラフ化。保存した記録は再生して聴き返すこともできます。
あえて生録音ではなく電子音で再生する設計にしてあり、音色などは無視して純粋なピッチの変化だけを確認できます。

### 楽器測定
楽器のクセを測定するためのモード。
３回吹いた音の平均ピッチが記録され、全音域を吹けばグラフで見られます。
保存・読み込みができて他のデータと比較もできるので、楽器同士で比べたり、パート内で合わせるための参考にできます。

### 設定
楽器・移調・音名表記・マイク感度の自動調整など。

### 統合版
